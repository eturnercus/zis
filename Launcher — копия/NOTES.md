# DynastyLauncher — зафиксированное поведение

## Закрытие лаунчера убивает клиент
- Java запускается в job object с `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE`.
- `StopGameClient()` вызывается из `WM_CLOSE` и `WM_DESTROY`.
- Закрытие окна лаунчера завершает Minecraft. Не оставлять клиент «осиротевшим».
- Статус после запуска: «Игра запущена. Закрытие лаунчера закроет клиент.»
- Проверка: `Launcher/tools/test_job.exe`.

## Без авто-входа на сервер
- `config/live.json` → `lock_to_server: false`.
- Лаунчер не передаёт `--quickPlayMultiplayer`.
- `servers.dat` перед запуском пишется пустым (старый список серверов не подхватывается).
- Игрок заходит на сервер сам из клиента.

## Автообновление exe
- При старте лаунчер качает `http://zis.inflexus.world/download/DynastyLauncher.exe.sha256`.
- Сравнивает SHA-256 с собой. Если другой — качает `DynastyLauncher.exe` с `/download/`, подменяет файл и открывается снова.
- Если sha256 на сайте нет или сеть упала — остаётся текущий exe.
- Сборка кладёт exe и `.sha256` в `site/download/` (`Launcher/build.bat`).
- На сервере `./watch-launcher-sha.sh` раз в минуту: SHA exe → `DynastyLauncher.exe.sha256`; если файлы в `cloud/` сменились — пересобирает `cloud/index.json`.
- Сборка из папки с `src/engine.cpp` автообновление пропускает (чтобы не затирать dev-exe).

## Ник и запуск
- Ник: 4–16 символов, латиница, цифры, `_` и `-`.
- Пока качается сборка или игра запущена, ник и память заблокированы. Кнопка «Логи» в настройках работает.
- На кнопке анимация «ЗАГРУЗКА…», после старта «В ИГРЕ» и окно сворачивается.
- Если клиент не стартовал или вылетел — микро-панель внутри лаунчера: скопировать `launcher.log` + хвост `minecraft.log`.

## Новости и кодекс
- Новости: `news.json` с сайта, картинки `/news-media/` включая WebP (WIC).
- Кодекс: `content.json` → `codex.rules`, тот же файл, что админка пишет на сайт.

## Админ API на Ubuntu
- Временно, в tmux/screen: `./private/run-admin-api.sh` (пока открыт терминал).
- Постоянно: `sudo ./start-zis.sh` — systemd + прокси nginx `/admin/api/`.
- Без nginx-прокси `/admin` с сайта всё равно даст 404, даже если python уже запущен.

## Новости
- По умолчанию лента пустая.
- Источник: `news_url` (`http://zis.inflexus.world/news.json`), тот же файл, что на сайте.
- Принимается только JSON с полем `"feed"` (старая лента BETA игнорируется).
- Картинки и GIF из `/admin` лежат в `/news-media/` и подтягиваются лаунчером.
- Замок keep.gif на вкладке «Игра» больше не рисуется.
